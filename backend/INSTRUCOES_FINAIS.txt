## 🚀 PARA COMEÇAR (Com Docker Funcionando)

### Passo 1: Abra o terminal

```powershell
cd C:\Desenvolvimento\ae-organiza-lar\backend
```

### Passo 2: Inicie os serviços

```bash
docker-compose up -d
```

**Aguarde ~10 segundos**

### Passo 3: Execute o backend

```bash
./mvnw quarkus:dev
```

**Aguarde ~20 segundos**

### Resultado Esperado

```
Quarkus 3.8.1 started in 1.234s
Listening on: http://0.0.0.0:8080
```

### Passo 4: Teste (em outro terminal)

```bash
bash test-api.sh
```
